      🔑 Cần khóa YouTube Data API v3 (miễn phí)

      1. Mở Google Cloud Console → YouTube Data API v3, đăng nhập Google, tạo hoặc chọn một dự án rồi bấm Enable (Bật).
      2. Vào APIs & Services → Credentials → Create credentials → API key, sao chép khóa (dạng AIza…).
      3. Dán vào ô dưới rồi bấm Lưu khóa. App kiểm tra khóa rồi lưu vào remotion-remake/.env (dòng YOUTUBE_API_KEY).
      Miễn phí 10.000 đơn vị quota mỗi ngày, không cần thẻ thanh toán. Mỗi lần tìm tốn khoảng 100–500 đơn vị tuỳ độ sâu.

      🔥 Tìm video có nhiều lượt xem, lượt thích và bình luận nhất
